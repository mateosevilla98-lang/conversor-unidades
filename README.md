# Súper Conversor de Unidades

## Descripción
Proyecto desarrollado en C++ para realizar conversiones matemáticas rápidas entre distintas unidades de medida desde la terminal.

## Objetivo
Aplicar el flujo de trabajo colaborativo en GitHub mediante el uso de ramas y resolución de conflictos.

## Funcionalidades
- Funcionalidades originales: Menú de consola.
- Aporte de Mate: Conversión de longitud (metros a kilómetros y millas).
- Aporte del Estudiante 2: Conversión de peso (gramos a kilogramos y libras).

## Tecnologías utilizadas
- C++
- Git
- GitHub
- VS Code

## Instalación y ejecución
Clonar el repositorio, compilar `conversor.cpp` mediante el comando `g++ conversor.cpp -o conversor` y ejecutar `./conversor`.

## Flujo de colaboración
Se clonó el repositorio, cada estudiante creó una rama `feature/`, realizó tres commits, generó un Pull Request, y se realizó revisión de código cruzada antes del merge.

## Conflicto resuelto
Se generó un conflicto en la primera línea de este archivo (título). Se resolvió analizando ambas ramas y combinando los nombres para dejar un título consensuado.

## Historial del proyecto
Se inició con un menú básico y se expandió a un conversor funcional de dos categorías (peso y longitud).
